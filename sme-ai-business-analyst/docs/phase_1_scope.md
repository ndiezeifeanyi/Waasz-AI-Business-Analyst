# Phase 1 Scope

Included:

- WhatsApp text, voice, and receipt/photo intake
- Sales, expense, and inventory update extraction
- Mandatory one-tap confirmation
- Daily summaries
- Weekly reports
- Founder monitoring dashboard
- Cost controls and secure defaults

Excluded until later phases:

- Forecasting
- Credit scoring
- Lending
- Multi-tenant billing automation
- Full customer web dashboard
